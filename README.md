# Animated Download Button ⬇️✨

This project features a modern **Animated Download Button** built using HTML, CSS, and JavaScript.  
When the user clicks the button, it shows a smooth animation — loading → progress → downloaded —  
giving a realistic and interactive download experience.

---

### ✨ Features
- Smooth click-to-download animation  
- Progress bar / loading animation  
- Checkmark confirmation after download  
- Fully responsive on all devices  
- Lightweight and fast (pure HTML, CSS, JS)

---

### 🛠️ Technologies Used
- **HTML**  
- **CSS**  
- **JavaScript**

---

### 💡 How to Use
1. Clone or download this repository.  
2. Open the `index.html` file in your browser.  
3. Click the **Download** button and watch the animation!
